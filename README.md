# Сайт Фонда имени Шейха Зайеда

Статический сайт: HTML, CSS и JavaScript, без PHP и баз данных. Подходит для любого хостинга —
достаточно загрузить содержимое папки (кроме `_src`) в корень сайта.

## Страницы

- `index.html` — главная
- `funding.html` — программы и условия финансирования, отрасли
- `calculator.html` — калькулятор платежа
- `review.html` — порядок рассмотрения заявки и документы для скачивания
- `apply.html` — анкета заявителя (все кнопки «Подать заявку» ведут сюда)
- `consulting.html` — консультации и запись
- `training.html` — обучение и запись на тренинги
- `projects.html` — архив проектов: 112 проектов с фото, поиск, фильтр по отрасли
- `about.html` — о фонде
- `contacts.html` — контакты, форма сообщения, карта
- `faq.html` — 35 вопросов и ответов, поиск
- `terms.html`, `privacy.html`, `personal-data.html` — документы

Тексты FAQ, документов и архива проектов перенесены со старого zayedfund.com; данные лежат в
`_src/data/` (`legal.json`, `projects.json`), страницы из них собирает `_src/build.py`.
Документы для скачивания — в `assets/docs/`.

Открыть локально: двойной щелчок по `index.html`.

## Как править

Страницы собираются из исходников в `_src`:

- `_src/pages/*.html` — содержимое страниц
- `_src/partials/` — общие блоки: шапка, подвал, иконки, калькулятор

После правки исходников: `python3 _src/build.py` — готовые страницы обновятся в корне папки.
Мелкие правки можно вносить и прямо в готовые `*.html`, но при следующей сборке они перезапишутся.

## Приём заявок

Формы записи на консультацию и заявки отправляют данные в формате JSON на адрес из
`assets/js/config.js` (`ZF_FORM_ENDPOINT`). Это может быть обработчик на сервере фонда
или входящий вебхук CRM (Битрикс24, amoCRM и т. п.).

Пока адрес не указан, форма не отправляется и предлагает позвонить или написать на почту.

Поля: `type` (`consult` или `apply`), `name`, `phone`, `date`, `sphere`, `district`, `amount`, `project`, `sent_at`.

## Анкета (apply.html)

Шаги: личные данные и паспорт → адрес → семья и образование → работа и финансы →
бизнес и проект (вид поддержки, опыт, источники) → документы.
Обязательные файлы: паспорт, личное фото, личное резюме, резюме бизнес-идеи; до 10 МБ каждый.
Шаблоны для скачивания лежат в `assets/docs/` (взяты со старого сайта).
Проверка полей и маски (телефон, паспорт, ИНН, индекс) — в `assets/js/apply.js`.

Анкета отправляется вместе с файлами (multipart/form-data) на `ZF_APPLY_ENDPOINT`
в `assets/js/config.js`. Повторяющиеся блоки приходят массивами: `edu_level[]`, `debt_creditor[]`,
`biz_name[]` и т. д. Блоки, выключенные переключателем, не отправляются.
Пока адрес пустой, анкета предлагает позвонить или написать на почту.

## Калькулятор

`assets/js/calc.js`, формула как в Excel-таблице фонда (лист «Традиционный займ»):
в льготный период наценка начисляется на сумму и прибавляется к долгу, далее равные платежи
ПЛТ(ставка/12; срок; долг). Льготный период — до 12 месяцев, срок — до 60 месяцев.

- Основная программа: ставка 13% (ячейка B11), льготный период 3 месяца.
- «Ламанхо»: ставка 8,74% — **в таблице не задана, подобрана так, чтобы наценка была 6% в год
  при сроке 4 года. Уточнить.**
